From inbox noise to a chosen next step.

Inbox Flight Deck asks Gemini for a plan, verifies its source quotes, and lets a person choose which decisions become local board entries. Rehearsal uses clearly labeled rules. This map is a reference route; it does not claim an owner-led code tour was performed.

Follow one action through three stops

Stop 1 — Visible input and feedback

Open src/App.tsx, find makePlan. It submits the current inbox and selected engine to /api/plan, shows loading or error state, and populates review cards. Find decisionCard to see the source quote, checkbox and category dropdown.

Stop 2 — Model output earns a preview

Open src/agent.ts, find geminiPlan and validatePlan. The former calls Google with a JSON schema; the latter checks every ID and exact body substring. src/server.ts connects them to the API. The model cannot directly mutate the board or send mail.

Stop 3 — Selected decisions become a reversible transaction

Open src/board.ts, find applyDecisions. It validates decisions again, moves the selected source messages into board entries and saves the previous snapshot. undoSession restores it. The browser's localStorage keeps the session; exportBrief turns the reviewed board into Markdown.

To change this, start here

  • Sample scenario: src/sample.ts → sampleMessages.
  • Visual identity or spacing: src/style.css → CSS variables and responsive rules.
  • AI behavior: src/agent.ts → system instruction and responseJsonSchema. Keep evidence checks.
  • Import limits or decision categories: src/shared.ts → shared schemas and parseInbox. Update UI and tests together.
  • Apply/undo behavior: tests/board.test.ts → subset and exact-restore checks.

A practice to reuse

Translate a product claim into an observable invariant. Here, “only approved changes happen” becomes “one deselected proposal stays in the inbox; undo restores the exact prior snapshot.” Board tests check the transaction, and the production browser test checks the same promise on screen. Exact quotes prove provenance; they do not prove a model's judgment is correct.

Run it again

From the repository: npm ci, npm run build, npm start. Open localhost:3000. No key is needed for rehearsal. Live mode requires a server-side Gemini key; see README.
